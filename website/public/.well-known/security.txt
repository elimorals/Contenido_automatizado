# Si descubriste una vulnerabilidad de seguridad en este proyecto
# (la plataforma Python, el sitio web, los workflows de ComfyUI, o
# cualquier endpoint expuesto en deploys de referencia), escríbenos
# directo. Respondemos en 72 horas hábiles.
#
# Coordinated disclosure: ventana estándar de 90 días antes de divulgar
# públicamente, extensible si el fix necesita más tiempo.
#
# Tipos de reportes que nos interesan:
#   - RCE / SSRF en la API REST
#   - Path traversal en file outputs
#   - Prompt injection con efecto pivote (escape de sandbox del LLM)
#   - Filtración de API keys de tenants en logs / responses
#   - Vulnerabilidades en dependencias críticas (ffmpeg, ComfyUI, etc.)

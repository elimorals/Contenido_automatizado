# scripts

Batch runners y utilidades. Portar de ambos repos en Fase 5-6.

## Planeados

- `run_topic_batch.py` — múltiples topics en paralelo (de reels-af)
- `run_arxiv_batch.py` — papers de arxiv (de reels-af)
- `bulk_publish.py` — publica todos los reels de un directorio a TikTok/IG
- `cost_report.py` — agrega costos de un día/semana/mes
- `cleanup_storage.py` — limpia tasks viejas y materials_cache
- `migrate_from_mpt.py` — utilidad para usuarios MPT existentes
